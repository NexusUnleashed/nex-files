# Colors

The Colors tab is in place, but color settings aren't available in the
window yet. For now:

- The colors of afflictions on the prompt, and of the prompt itself, can be
  changed with a few lines of script. See
  [Custom prompt](../custom-prompt.md#change-colors-and-abbreviations).
- Affliction and defence colors in the configuration window come from the
  nexSys theme.

This page will describe the color settings once they're released.
